## Статус передачи команде

### Закрыто

- Основные маршруты, tenant isolation, roles, справочники и их жизненный цикл, карточки с custom fields, компания/профиль.
- Печатные формы, XLSX/CSV, QR, план этажа, инвентаризация, списание и audit.
- Проверенная независимая сборка FE/BE, собственные DB/session/storage и рубежи продакшен-поставки.
- Документы для onboarding, предметные контракты, резервирование и rollback (см. также Backend docs).

### Требует отдельной подписи (не заменяется SQLite smoke)

- Реальная PostgreSQL 16 матрица на отдельном CI service, миграции и все ограничения FK; необходимо проверять именно драйвер pgsql, а не имя workflow.
- Восстановление резервной копии в отдельной изолированной БД с подписанным RPO/RTO и понятными владельцами доступа.
- Производительность на 10k+ активов/больших CSV/XLSX и конкурирующие операции, проверка NTFS ACL для private uploads.
- Формальная production роль-приёмка на рабочих ролях в контролируемом окне; бизнес-подпись владельца процесса.
- Сложный password rotate-and-restore regression с двумя соответствующими политике паролями: прежний hex-only QA secret не годился для новой установки.

## Технические улучшения

P0: документация источника истины, разделение legacy/modern, ленивые frontend модули, единый контракт роли на Backend, восстановление PostgreSQL CI, PR checklist и production runbooks.

P1: дробить крупные Vue страницы и PHP контроллеры на небольшие бизнес-компоненты без перезаписи логики; профилировать запросы и индексы на data volume, держать единый типизированный contract API; централизовать ошибки/логирование на всех маршрутах.

P2: совместимый версионированный общий UI пакет с HRM/Portal после smoke; SSO и ERP/1C через tenant-scoped интеграционный gateway, idempotent imports, mapping/dry-run и аудит.

## Definition of Done

API контракт + role matrix, RU/EN/GE/light-dark/mobile, миграционный план, unit/feature + реальный E2E, документация + release notes + rollback, независимый review, green CI, postrelease smoke соседних приложений. Кнопка UI без защищенного API — не завершенная функция.
