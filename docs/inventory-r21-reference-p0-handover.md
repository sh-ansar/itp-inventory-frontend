## Выполненные работы
- Раздел справочников объединяет типы имущества и оба вида мест учёта; добавлены ссылки на существующие реестры людей, складов, объектов и доступа.
- Добавлено изменение мест учёта; архивирование типов имущества и мест учёта без удаления исторических связей, с проверкой роли и версии.
- Справочники разделяются по компании; код и нормализованное название мест защищены ограничениями уникальности в PostgreSQL.
- Архивные позиции показываются в административном справочнике по переключателю, но больше не доступны для новых назначений.
- Исправлена двойная визуальная рамка у поискового поля в BaseMultiSelect, без смены поведения фильтров.
